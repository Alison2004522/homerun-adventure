# 《全壘打大作戰》（Home Run Adventure）
## 大聯盟球場科學與總管決策版

結合**閱讀理解**、**球場策略決策**與**拋體物理模擬**的素養導向棒球教育遊戲！

本遊戲靈感取材自大聯盟真實歷史（紐約大都會隊縮短圍牆、波士頓紅襪隊加高 11 公尺「綠色怪物」、科羅拉多落磯隊高山稀薄空氣與超大號全壘打）。學生在遊戲中同時扮演**「球團總管」**與**「王牌打者」**，透過「知識情境決策」引導動機，再透過「親自揮棒擊球」印證物理規律！

---

## 🎮 核心教育特色與升級重點

1. **情境式知識決策（引起動機）**：
   - 每一關開始前，進入「球團總管決策室」，面對真實球隊困境進行策略改建選擇（例如打者低潮時縮短圍牆、市區腹地不足時加高圍牆、高山稀薄空氣時拉遠圍牆）。
   - 點選後立即獲得**「MLB 真實歷史知識小百科」**解析，不論選對選錯皆有生動詼諧的引導。
2. **球場改建與實踐驗證（做中學）**：
   - 決策完成後立即踏入改建後的球場，親自調整**擊球角度**與**擊球力道**，驗證全壘打牆高度與距離對打擊結果的影響。
3. **純正原生效能與零外部依賴**：
   - 使用 HTML5、CSS3、原生 JavaScript（Canvas 2D 渲染與 Web Audio API 程序化合成音效），無須後端、無須資料庫、零 CDN 失效風險。
4. **跨載具響應式設計**：
   - 橫向 16:9 黃金比例，支援電腦滑鼠、平板觸控與手機操作。

## 🚀 部署指南

### 部署至 Cloudflare Pages
1. 進入 Cloudflare Dashboard ➔ **Workers & Pages** ➔ **Create application** ➔ **Upload your static files**。
2. 拖曳上傳 `全壘打大作戰_Cloudflare部署包` 資料夾（或解壓縮後的檔案）。
3. 點選 **Deploy**，數秒內即可上線發布。

### 部署至 GitHub Pages
1. 建立公開儲存庫（Public Repository）。
2. 將所有檔案拖曳上傳或以 Git 推送至 `main` 分支。
3. 進入儲存庫 **Settings** ➔ **Pages** ➔ Branch 選擇 `main`，點擊 **Save** 即可。

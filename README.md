# 《喵喵情緒偵探》（Cat Detective）
## 貓咪肢體語言觀察推理 ． 2D 互動式教育遊戲

結合**閱讀理解**、**觀察推理**與**生活應用**的 2D 互動式貓咪情緒判讀教育遊戲！

本遊戲專為國小高年級（五、六年級）至國中一年級學生設計。貓咪雖然不會直接說人類的語言，但會透過**耳朵、尾巴、眼睛、被毛、背部與姿勢**偷偷傳遞情緒訊號。玩家將化身為「喵喵情緒偵探」，接受三位飼主的委託，透過點擊身體部位蒐集線索、綜合推理，讀懂貓咪的真正心情並做出最適當的互動應對。

---

## 🎯 核心教育理念與學習重點

1. **多部位綜合判讀**：
   貓咪的情緒可以從耳朵、眼睛、尾巴、背部、被毛、前腳、腹部與牙齒等部位判讀。**單一訊號不一定代表唯一答案，必須結合多個線索綜合研判**（例如瞳孔放大可能放鬆也可能興奮想玩，需搭配尾巴直立與姿勢判斷）。
2. **理解適應需求**：
   貓咪剛到新環境容易緊張害怕，需要安靜的空間與時間慢慢適應，切忌強行抱摸。
3. **安全互動界線**：
   當貓咪出現炸毛、拱背、劇烈甩尾或露牙哈氣等生氣或攻擊警戒訊號時，人類應立即**停止接觸、保持安全距離**。
4. **生命教育責任感**：
   以尊重與同理心對待毛小孩，落實**「認養不棄養」**，做個負責任的貼心飼主。

## 🛠️ 技術規格與亮點

- **純原生開發（Zero Dependencies）**：
  - 核心語言：HTML5、CSS3、原生 JavaScript（ES6+）。
  - 不使用任何大型外部框架（No React / No Vue），零打包負擔。
- **Web Audio API 純程式合成音效**：
  - 不依賴任何外部音訊檔案或 CDN，由程式透過振盪器（Oscillator）即時運算合成（包含泡泡點擊音、水晶鈴聲、清亮和弦、柔和提示音與通關號角）。
  - 徹底杜絕瀏覽器跨網域 CORS 阻擋、404 資源缺失或載入延遲問題。
- **日系 2D 卡通向量美術（Scalable Vector Graphics）**：
  - 每一隻貓咪皆以乾淨柔和的 SVG 向量圖形即時渲染，支援高解析度 Retina 螢幕。
  - 包含生動微動態（呼吸起伏、擺動晃尾、劇烈甩尾、熱點光暈波紋）。
- **完全響應式佈局**：
  - 採 16:9 黃金比例視窗，自動自適應電腦螢幕、iPad/Android 平板及手機直橫螢幕。
- **無障礙與防呆機制**：
  - 超過 12 秒無動作自動觸發溫馨指引氣泡。
  - 點擊熱點即時更新已蒐集線索計數與筆記標籤。

## 🚀 部署至 GitHub Pages 指南

本專案為純靜態網站，無需安裝 Node.js 或執行任何 `npm build` 指令，可直接透過 GitHub Pages 上線：

1. **建立 GitHub 儲存庫**：
   - 在 GitHub 上建立一個新的公開儲存庫（Public Repository），例如 `cat-detective`。
2. **推送專案檔案至 main 分支**：
   - 確保根目錄包含 `index.html`、`style.css`、`game.js`、`.nojekyll` 與 `assets/` 資料夾。
3. **開啟 GitHub Pages 服務**：
   - 進入儲存庫的 **Settings**（設定）分頁。
   - 在左側選單點選 **Pages**。
   - 在「Build and deployment」區塊的 **Branch** 下拉選單選擇 `main` 分支，資料夾選擇 `/(root)`。
   - 點擊 **Save**（儲存）。
4. **立即體驗遊玩**：
   - 等待約 1～2 分鐘，頁面上方會顯示綠色已發布網址（例如 `https://<你的帳號>.github.io/<專案名稱>/`），點擊即可在任何裝置的瀏覽器中直接遊玩！
